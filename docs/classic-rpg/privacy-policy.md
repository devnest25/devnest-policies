# 클래식 RPG 개인정보처리방침

시행일 및 최종 수정일: **2026년 11월 27일**

**DevNest**(이하 “개발자”)는 **클래식 RPG : 방치형 키우기(Classic RPG)**에서 처리하는 정보와 이용자의 선택을 다음과 같이 안내합니다. 출시용 패키지는 `com.devnest.classicrpg`, 개발용 패키지는 `com.devnest.classicrpg.dev`입니다. 이전 개발용 `org.devnest25.classicrpg.dev` 배포본에도 해당 기능의 처리 방침이 적용됩니다.

이 방침은 로컬 플레이와 선택적 Google Drive 수동 클라우드 저장을 대상으로 합니다. Google 연결 없이 로컬 플레이가 가능하며 별도의 DevNest 회원가입이나 개발자 운영 게임 서버는 사용하지 않습니다. 방침 열람·설치·계속 이용을 선택적 Google 정보 접근에 대한 동의로 간주하지 않습니다.

## 1. 처리하는 정보와 목적

| 구분 | 정보 | 목적·처리 위치 |
| --- | --- | --- |
| 게임 진행·설정 | 레벨·경험치·재화, 강화·스킬·펫·전리품, 사냥 진행과 저장 시각, 화면·음향 설정 등 | 기기 내부에서 진행 저장·복원과 설정 유지 |
| 선택적 Google 연결 | 선택한 Google 계정의 이메일 주소, Google Drive 사용자 식별값(permissionId), 연결 상태 | 앱 실행 중 계정 표시·일치 확인·잘못된 계정에 저장하거나 복원하는 것 방지 |
| 접근 권한 정보 | Google이 발급한 접근 토큰 | 사용자가 요청한 Google Drive API 작업의 인증. 앱의 요청 처리 메모리에서 사용하며 앱 파일·로그에 저장하지 않음 |
| 선택적 클라우드 저장 | 게임 진행 JSON과 그 안에 포함된 표시 설정, 저장 형식 버전, 파일 식별자·수정 시각·버전 등 메타데이터 | 사용자가 수동 저장·불러오기를 요청할 때 본인 Google Drive의 앱 전용 영역에서 백업·복원 |
| 문의 자료 | 이메일 주소·문의 내용 및 이용자가 선택하여 첨부한 자료 | 이메일을 통한 문의 응대·오류 확인·개인정보 권리 요청 처리 |
| 정책 웹페이지 접속 | IP 주소, 요청 경로 등 호스팅 접속 정보 | GitHub Pages의 페이지 제공·보안. 앱의 게임 저장본을 정책 페이지 요청에 첨부하지 않음 |

계정 이메일과 Drive 사용자 식별값은 앱에서 연결 상태 확인에 사용하며 별도 개발자 서버로 전송하거나 게임 진행 저장본에 넣지 않습니다. Google 서비스 자체의 인증 정보 보관은 Google 정책과 계정 설정을 따릅니다. 음향 설정 파일은 클라우드에 전송하지 않으며, 복원할 때 기기 전용 표시 설정은 대상 기기의 값을 유지합니다.

현재 이 방침이 다루는 앱에는 AdMob 광고, Google Play 인앱결제, 공개 랭킹, 독립 분석·크래시 수집 SDK가 포함되어 있지 않습니다. 해당 기능을 도입하여 정보 처리가 달라지면 적용 전에 방침과 필요한 동의 안내를 갱신합니다.

## 2. Google 연결과 수동 클라우드 저장

앱 설정에서 이용자가 Google 연결과 권한 허용을 선택하면 Google 인증 서비스를 통해 계정과 접근 권한을 확인합니다. 앱이 Google 비밀번호를 직접 입력받거나 보관하지 않습니다.

요청 권한은 `https://www.googleapis.com/auth/drive.appdata`입니다. 이 권한은 해당 앱의 숨김 앱 전용 데이터 영역에 접근하기 위한 것으로, 일반 Drive 문서·사진·연락처 전체에 대한 접근 권한을 요청하지 않습니다.

- 계정 연결 시 계정 정보와 기존 저장본의 메타데이터를 확인합니다. 연결만으로 게임 진행을 업로드하거나 덮어쓰지 않습니다.
- **클라우드 저장**을 누르면 진행 데이터를 Google Drive로 전송합니다. 자동·주기 업로드나 다기기 실시간 동기화를 제공하지 않습니다.
- **불러오기**를 누르면 저장본을 내려받고 교체 확인 후 현재 진행에 적용합니다. 복원 전에 기기 내부에 이전 정상 진행의 안전 백업을 남깁니다.
- 앱의 **연결 해제**는 앱 세션의 연결 해제입니다. Google 계정의 권한 철회나 클라우드 저장본 삭제를 뜻하지 않습니다.
- 앱 재실행 후 클라우드를 이용하려면 다시 명시적으로 연결합니다. Google 서비스에 남은 권한·인증 상태는 Google 계정 설정에서 별도로 관리할 수 있습니다.

Google API에서 받은 정보는 요청한 계정 확인·게임 저장·복원에만 사용하며 판매하거나 광고 타기팅에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 이전은 제한적 사용 요건을 포함한 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)을 준수합니다.

## 3. 외부 서비스와 안전한 처리

- **Google:** Google 계정 인증·권한 확인, Drive 저장·복원 및 문의 이메일(Gmail) 처리를 제공합니다. 서비스 요청에 수반되는 IP 주소·기기/서비스 정보 등 Google 자체의 처리 범위와 보관은 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)을 따릅니다.
- **GitHub:** 이 정책 웹사이트를 GitHub Pages로 제공합니다. 접속 정보의 처리는 [GitHub 개인정보처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)과 [Pages 접속 정보 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)를 따릅니다.

Google Drive 통신에는 HTTPS를 사용합니다. 앱은 인증 토큰·계정 식별값·저장본 본문을 진단 로그에 기록하지 않도록 처리합니다. 기기 내부의 진행 파일을 별도로 암호화된 금고로 제공하는 것은 아닙니다. 개발자는 이용자가 문의로 제공한 경우를 제외하고 별도 게임 서버에서 저장본을 수신·열람하지 않습니다.

외부 서비스의 정보는 한국 외의 국가에서 처리될 수 있습니다. 제공자의 처리 위치·보호 조치에 관한 안내는 각 정책에서 확인할 수 있습니다. Google 연결을 선택하지 않으면 앱의 선택적 Drive 전송 없이 로컬 플레이를 이용할 수 있습니다. 개발자는 개인정보를 판매하지 않습니다.

## 4. 보관 기간과 삭제 방법

**기기 내부 데이터:** 게임 진행·설정·안전 백업은 기능 제공과 복원을 위해 앱 저장 공간에 보관합니다. Android 설정 → 앱 → 클래식 RPG(개발용은 클래식 RPG Dev) → 저장 공간 → **데이터 삭제**로 삭제할 수 있습니다. 기기별 메뉴명은 다를 수 있습니다. 운영체제의 별도 백업이 있는 경우 해당 기기·계정 백업 설정에서도 관리해야 합니다.

**Google Drive 저장본:** 수동으로 저장한 진행은 이후 저장으로 갱신되거나 이용자가 삭제할 때까지 Google Drive에 보관됩니다. 기기의 앱 데이터 삭제·앱 제거·앱 내 연결 해제만으로 클라우드 저장본이 삭제되는 것은 아닙니다.

1. 저장에 사용한 Google 계정으로 PC 웹의 [Google Drive 설정](https://drive.google.com/drive/settings)에 접속합니다.
2. **앱 관리**에서 Classic RPG / 클래식 RPG에 해당하는 연결 앱을 찾습니다.
3. 해당 앱의 **옵션 → 숨겨진 앱 데이터 삭제**를 선택합니다. 화면·항목은 계정과 Google의 UI에 따라 다를 수 있습니다.
4. 향후 접근 권한도 없애려면 [Google 계정의 타사 연결](https://myaccount.google.com/connections)에서 해당 앱의 연결·권한을 제거합니다. **권한 철회와 저장본 삭제는 별개의 조치**입니다.

[Google의 저장 공간·숨겨진 앱 데이터 삭제 안내](https://support.google.com/drive/answer/6374270?hl=ko)를 참고하세요. 목록이 보이지 않거나 삭제가 어려우면 아래 문의처로 연락해 주세요. 로컬 진행을 남겨 둔 뒤 다시 수동 저장하면 클라우드 저장본이 다시 만들어질 수 있습니다. 개발자는 사용자의 Google 계정 전체나 Google이 별도로 보관하는 서비스 기록을 대신 삭제할 수 없습니다.

**계정 정보·토큰:** 앱의 연결 상태는 실행 중 메모리에서 처리하며 앱 종료 후 게임 저장 파일에 보관하지 않습니다. Google 자체의 인증·보안 기록은 Google 정책을 따릅니다.

**문의 자료:** 문의·권리 요청 처리에 필요한 동안 보관하고 목적 달성 후 지체 없이 삭제합니다. 법령에 따라 보존이 필요한 자료는 해당 의무에 필요한 범위·기간에 한해 보관합니다. 보유한 문의 자료의 삭제를 요청할 수 있습니다.

**호스팅 접속 정보:** GitHub와 Google이 서비스 제공자로서 관리하는 기록의 보관·삭제는 각 서비스 정책과 요청 절차를 따릅니다.

아동의 정보 처리에 관한 문의와 권리 요청은 보호자가 같은 연락처로 할 수 있습니다. Google 계정의 연령·보호자 제한은 Google 서비스 설정을 따릅니다.

## 6. 방침 변경

정보 처리 방식이 달라지면 시행일·수정일과 본문을 갱신하고 필요한 경우 앱 또는 스토어에서 별도로 알립니다. 필요한 선택적 권한·동의는 해당 기능에서 별도로 요청합니다.

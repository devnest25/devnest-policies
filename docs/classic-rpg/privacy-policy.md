# 클래식 RPG 개인정보처리방침

시행일 및 최종 수정일: **2026년 11월 27일**

**DevNest**(이하 “개발자”)는 **클래식 RPG : 방치형 키우기(Classic RPG)**에서 처리하는 정보와 이용자의 선택을 다음과 같이 안내합니다. 출시용 패키지는 `com.devnest.classicrpg`, 개발용 패키지는 `com.devnest.classicrpg.dev`입니다. 이전 개발용 `org.devnest25.classicrpg.dev` 배포본에도 해당 기능의 처리 방침이 적용됩니다.

이 방침은 PGS 전환 버전의 로컬 플레이와 Google Play Games Services(PGS) v2 인증·선택적 Saved Games 수동 저장을 대상으로 합니다. 기존 Drive 직접 연동 배포본은 업데이트 전까지 종전 방식으로 동작하며 기존 데이터를 자동 이전하거나 삭제하지 않습니다. 로그인 없이 로컬 플레이가 가능하며 별도의 DevNest 회원가입이나 개발자 운영 게임 서버는 사용하지 않습니다. 방침 열람·설치·계속 이용을 선택적 Google 정보 접근에 대한 동의로 간주하지 않습니다.

## 1. 처리하는 정보와 목적

| 구분 | 정보 | 목적·처리 위치 |
| --- | --- | --- |
| 게임 진행·설정 | 레벨·경험치·재화, 강화·스킬·펫·전리품, 사냥 진행과 저장 시각, 화면·음향 설정 등 | 기기 내부에서 진행 저장·복원과 설정 유지 |
| Play Games 인증 | PGS 플레이어 ID, 표시 이름, 인증 상태 | 앱 실행 중 플레이어 표시·계정 일치 확인·잘못된 계정에 저장하거나 복원하는 것 방지 |
| 선택적 Saved Games | 게임 진행 JSON과 그 안에 포함된 표시 설정, 저장 형식 버전·슬롯·수정 시각·동기화 대기 상태 등 메타데이터 | 수동 저장·불러오기 요청에 따른 Google Saved Games 백업·복원. SDK의 기기 캐시 및 지연 동기화 포함 |
| PGS SDK 서비스 정보 | Google의 안내에 따른 기기·계정 식별자, 게임 이용·성능/진단 정보 등 | Google의 게임 서비스 제공·분석·진단. 실제 SDK 처리 범위는 아래 공식 안내 참조 |
| 문의 자료 | 이메일 주소·문의 내용 및 이용자가 선택하여 첨부한 자료 | 이메일을 통한 문의 응대·오류 확인·개인정보 권리 요청 처리 |
| 정책 웹페이지 접속 | IP 주소, 요청 경로 등 호스팅 접속 정보 | GitHub Pages의 페이지 제공·보안. 앱의 게임 저장본을 정책 페이지 요청에 첨부하지 않음 |

PGS 플레이어 ID와 표시 이름은 앱 실행 중 계정 확인에 사용하며 별도 개발자 서버로 전송하거나 게임 진행 저장본에 넣지 않습니다. 앱은 이메일·Drive permissionId·접근 토큰을 직접 조회하거나 저장하지 않습니다. Google 서비스 자체의 인증 정보 보관은 Google 정책과 계정 설정을 따릅니다. 음향 설정 파일은 클라우드에 전송하지 않으며, 복원할 때 기기 전용 표시 설정은 대상 기기의 값을 유지합니다.

현재 이 방침이 다루는 앱에는 AdMob 광고, Google Play 인앱결제, 공개 랭킹, 독립 분석·크래시 수집 SDK가 포함되어 있지 않습니다. 해당 기능을 도입하여 정보 처리가 달라지면 적용 전에 방침과 필요한 동의 안내를 갱신합니다.

## 2. Play Games 인증과 수동 Saved Games

PGS v2 SDK는 게임 시작 시 Google 계정·Play Games 설정에 따라 자동 인증을 시도할 수 있습니다. 앱은 인증 상태를 확인하고 필요할 때 로그인 요청을 제공합니다. 로그인하지 않거나 네트워크가 없어도 로컬 플레이가 가능합니다. 앱이 Google 비밀번호를 직접 입력받거나 보관하지 않습니다.

- 인증 성공만으로 게임 진행을 업로드하거나 덮어쓰지 않습니다. **클라우드 저장**과 **불러오기**는 사용자가 설정에서 요청합니다.
- Saved Games에 필요한 Google 내부 앱 전용 저장 권한과 SDK 처리를 사용합니다. 앱이 Drive REST 또는 AuthorizationClient로 직접 일반 Drive 문서·사진·연락처를 조회하는 방식은 사용하지 않습니다.
- 앱은 자동·주기 저장 업로드를 요청하지 않습니다. 다만 SDK가 이미 접수한 저장을 기기에 캐시하고 네트워크 복구 뒤 동기화할 수 있습니다. SDK 접수는 서버 동기화 완료를 보장하지 않으며 읽은 저장도 캐시를 포함할 수 있습니다.
- 불러온 데이터를 검증하고 로컬/클라우드 진행·저장 시각을 보여 줍니다. 이용자의 교체 확인과 계정 재확인 후 복원하며, 직전 정상 로컬 진행을 별도 백업합니다. 재화·경험치·아이템을 합산하지 않습니다.
- 충돌 시 보존할 클라우드 버전을 선택하거나 취소할 수 있습니다. 선택하지 않은 클라우드 버전은 대체될 수 있으며 로컬 복원에는 별도 확인이 필요합니다.
- 개발용과 배포용 앱은 같은 PGS 프로젝트 안에서 서로 다른 저장 슬롯을 사용합니다.
- 계정 변경·자동 인증 설정은 [Google 공식 Play Games 계정 관리 안내](https://support.google.com/googleplay/answer/3129346?hl=ko)를 따릅니다. 앱에는 Google 로그아웃·권한 철회·원격 데이터 삭제를 수행하는 버튼이 없습니다.

Google API에서 받은 정보는 계정 확인·게임 저장·복원에 사용하며 판매하거나 광고 타기팅에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 이전은 제한적 사용 요건을 포함한 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)을 준수합니다. SDK의 정보 처리 항목은 [PGS 데이터 공개 안내](https://developer.android.com/games/pgs/data-collection)를 참고하세요.

## 3. 외부 서비스와 안전한 처리

- **Google:** Play Games 인증, Saved Games 저장·복원 및 문의 이메일(Gmail) 처리를 제공합니다. 서비스 요청에 수반되는 IP 주소·기기/서비스 정보 등 Google 자체의 처리 범위와 보관은 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)을 따릅니다.
- **GitHub:** 이 정책 웹사이트를 GitHub Pages로 제공합니다. 접속 정보의 처리는 [GitHub 개인정보처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)과 [Pages 접속 정보 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)를 따릅니다.

PGS SDK는 Google 서비스와 통신할 때 전송 중 암호화를 사용합니다. 앱은 인증 토큰·계정 식별값·저장본 본문을 진단 로그에 기록하지 않도록 처리합니다. 기기 내부의 진행 파일을 별도로 암호화된 금고로 제공하는 것은 아닙니다. 개발자는 이용자가 문의로 제공한 경우를 제외하고 별도 게임 서버에서 저장본을 수신·열람하지 않습니다.

외부 서비스의 정보는 한국 외의 국가에서 처리될 수 있습니다. 제공자의 처리 위치·보호 조치에 관한 안내는 각 정책에서 확인할 수 있습니다. 수동 클라우드 저장을 요청하지 않아도 로컬 플레이를 이용할 수 있습니다. PGS 자동 인증 및 SDK가 접수한 저장의 후속 동기화는 Google 계정·서비스 설정에 따라 별도로 동작할 수 있습니다. 개발자는 개인정보를 판매하지 않습니다.

## 4. 보관 기간과 삭제 방법

**기기 내부 데이터:** 게임 진행·설정·안전 백업은 기능 제공과 복원을 위해 앱 저장 공간에 보관합니다. Android 설정 → 앱 → 클래식 RPG(개발용은 클래식 RPG Dev) → 저장 공간 → **데이터 삭제**로 삭제할 수 있습니다. 기기별 메뉴명은 다를 수 있습니다. 운영체제의 별도 백업이 있는 경우 해당 기기·계정 백업 설정에서도 관리해야 합니다.

**Saved Games 저장본:** 사용자가 요청한 저장은 Google 서비스에 보관되며 기기의 SDK 캐시가 남을 수 있습니다. 앱 제거·기기 데이터 삭제만으로 Google 저장본이 삭제되지는 않습니다. 저장 접수 직후에는 서버 반영이 끝나지 않았을 수 있으므로 다른 설치에서 확인하기 전 앱 데이터를 지우지 마세요.

Google Play Games의 설정에서 **Play Games 계정 및 데이터 삭제 → 개별 게임 데이터 삭제**에 해당하는 항목을 찾아 Classic RPG 데이터를 관리할 수 있습니다. 기기·계정별 화면은 달라질 수 있으므로 [Google 공식 삭제 안내](https://support.google.com/googleplay/answer/9130646?hl=ko)를 따르세요. 같은 PGS 프로젝트의 개발·배포 슬롯이 함께 영향을 받을 수 있습니다. 로컬 진행 삭제·Google 계정 권한 관리·게임 데이터 삭제는 서로 다르며, Google 자체 기록의 삭제 범위·시점은 Google 정책을 따릅니다.

기존 Drive 직접 연동 버전이 만든 숨겨진 앱 데이터는 자동 삭제·이전하지 않습니다. 해당 과거 저장본은 [Google Drive 설정](https://drive.google.com/drive/settings)의 앱 관리·숨겨진 앱 데이터 삭제와 [공식 안내](https://support.google.com/drive/answer/6374270?hl=ko)를 참고하세요. Google 권한 철회가 저장본 삭제와 같은 동작이라고 보장하지 않습니다.

로컬 진행을 남긴 뒤 다시 수동 저장하면 Google 저장본이 다시 생성될 수 있습니다. 이미 SDK가 접수한 저장의 지연 동기화와 삭제 결과·반영 시점은 실제 계정에서 확인해야 하며 개발자가 Google 전체 데이터의 삭제를 대신 수행하거나 기한을 보장하지 않습니다.

**플레이어 정보:** 앱의 플레이어 ID·표시 이름·인증 상태는 실행 중 메모리에서 처리하며 게임 저장 파일에 보관하지 않습니다. SDK가 관리하는 인증·캐시·서비스 기록은 Google 정책을 따릅니다.

**문의 자료:** 문의·권리 요청 처리에 필요한 동안 보관하고 목적 달성 후 지체 없이 삭제합니다. 법령에 따라 보존이 필요한 자료는 해당 의무에 필요한 범위·기간에 한해 보관합니다. 보유한 문의 자료의 삭제를 요청할 수 있습니다.

**호스팅 접속 정보:** GitHub와 Google이 서비스 제공자로서 관리하는 기록의 보관·삭제는 각 서비스 정책과 요청 절차를 따릅니다.

이용자는 적용 법령에 따라 개인정보의 열람·정정·삭제·처리 정지·동의 철회 등을 요청할 수 있습니다. 개발자가 처리하는 문의 자료나 게임의 정보 처리에 관한 요청은 다음 연락처로 보내 주세요.

- 이메일: [devnest25@gmail.com](mailto:devnest25@gmail.com)

요청 대상과 필요한 조치 범위를 최소한으로 확인한 뒤 적용 법령의 절차에 따라 응답합니다. 문의에 Google 비밀번호·인증 코드·접근 토큰을 보내지 마세요. 기기에만 있는 데이터와 이용자 Google 저장본은 위 직접 삭제 경로를 안내하며 개발자의 원격 삭제를 보장하지 않습니다. 별도 DevNest 게임 회원계정은 생성하지 않습니다.

아동의 정보 처리에 관한 문의와 권리 요청은 보호자가 같은 연락처로 할 수 있습니다. Google 계정의 연령·보호자 제한은 Google 서비스 설정을 따릅니다.

## 6. 방침 변경

정보 처리 방식이 달라지면 시행일·수정일과 본문을 갱신하고 필요한 경우 앱 또는 스토어에서 별도로 알립니다. 필요한 선택적 권한·동의는 해당 기능에서 별도로 요청합니다.

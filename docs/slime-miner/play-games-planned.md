# Google Play 게임즈 백업·복원 — 적용 예정 변경안

작성일: 2026년 10월 15일 / 상태: 미구현·미시행. 이 문서는 현재 제공되는 기능의 개인정보처리방침이 아닙니다. [현재 방침 초안](privacy-policy.html)의 시행일이나 제공 기능을 변경하지 않습니다.

## 도입 목적과 이용자의 선택
기기 변경·재설치 시 진행도를 복원하기 위해 Google Play Games Services Saved Games를 도입할 예정입니다. 로그인 없이 로컬 플레이를 유지하고, 설정에서 게임즈 연결을 선택한 후 수동으로 저장·불러오기를 제공하는 범위입니다. 연결만으로 진행도를 자동 업로드하거나 덮어쓰지 않는 방향입니다.

PGS v2 SDK는 자동 인증을 시도할 수 있습니다. 실제 인증 시점·프로필 생성·계정 변경 동작은 Godot 연동 검증 후 공개 방침에 정확히 기재합니다. 모든 인증이 설정 버튼을 누른 뒤에만 발생한다고 아직 단정하지 않습니다.

## 저장·보관·삭제 및 연결 해제
- 기기 로컬 저장과 복원 전 안전 백업은 기기 내부에서 관리할 예정입니다. 백업 파일명·보관 개수/기간·삭제 방법은 구현 검증 후 공개 방침에 반영합니다.
- 클라우드 저장본은 Google 계정에 연결되는 Google Saved Games에서 관리될 예정입니다. 정확한 보관·삭제 반영 기간은 확인 없이 숫자로 약속하지 않습니다.
- 앱 데이터 삭제·앱 제거, 게임즈 연결 해제/계정 변경, 클라우드 게임 데이터 삭제는 서로 다른 조치입니다. 연결 해제만으로 클라우드 저장본이 삭제되었다고 안내하지 않습니다.
- Google은 게임즈 프로필 설정에서 게임별 게임 데이터를 삭제하는 절차를 안내합니다. [공식 삭제 안내](https://support.google.com/googleplay/answer/9130646)를 제공하고 실제 Saved Games 저장본에 대한 삭제 결과를 도입 전에 검증합니다.
- 로컬 데이터는 Android 앱 저장 데이터 삭제로 별도 삭제할 수 있습니다. OS 백업이 존재할 수 있고, Google 게임즈 데이터 삭제가 개발자에게 별도 제공된 문의 내용까지 지우지는 않습니다.
- 계정 연결 해제/변경은 Google이 제공하는 게임즈/계정 관리 설정으로 안내할 예정입니다. 제공되지 않는 인앱 로그아웃 또는 원격 삭제 기능을 약속하지 않습니다. 삭제 후 기존 로컬 진행을 다시 수동 업로드하면 새 백업이 생성될 수 있음을 안내합니다.

Google 서비스 인프라에서 인증·클라우드 저장 정보가 처리될 예정이며, 실제 수령 주체·국외 처리/이전 고지와 법적 근거는 출시 국가 및 적용 요구사항 확인 후 확정합니다. 출시 대상 연령·국가는 미확정이며 아동 대상 여부를 추정하지 않습니다.
